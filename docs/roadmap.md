# Development Directions

RepoLens provides evidence-grounded repository analysis, scoped retrieval, bounded evidence exploration, reproduction planning, verification questions, Markdown export, and a native macOS evidence workspace.

Planned extensions focus on research-team workflows:

- reviewer annotations and comparison;
- revision-to-revision evidence tracking;
- secure cross-device research collections;
- shared experiment records and report versions;
- broader evaluation across notebooks and research monorepos; and
- opt-in sandboxed execution with explicit human approval.

These extensions retain the same source-evidence, immutable-revision, and server-validation boundaries used by the current product.
